# Mente Sana — primera página web

Proyecto escolar de Programación B5B. Sitio informativo sobre la carrera de Psicología.

## Archivos
- `index.html`: estructura y contenido de la página.
- `styles.css`: colores, distribución y adaptación a pantallas pequeñas.

## Cómo verlo
1. Descarga y descomprime el ZIP.
2. Abre `index.html` en un navegador.
3. Para editar, abre ambos archivos en un editor de código.

## Publicar con GitHub Pages
1. Crea un repositorio público llamado `TU-USUARIO.github.io`.
2. Sube `index.html` y `styles.css` a la raíz del repositorio.
3. En Settings > Pages, selecciona `Deploy from a branch`, rama `main` y carpeta `/ (root)`.
4. Guarda y espera a que GitHub publique el sitio.
5. Abre `https://TU-USUARIO.github.io`.

Reemplaza `TU-USUARIO` por tu usuario exacto de GitHub.

## Personalización
Cambia el texto del pie de página por tu nombre y grupo antes de entregar.
El sitio usa HTML y CSS; no necesita JavaScript porque la navegación funciona con enlaces internos.
